# 0001: Orot 저장소 구조

- 날짜: 2026-11-03
- 범위: 프로젝트 이름과 디렉터리 구조 변경

## 결정

기존 Git 이력과 사용자 작업 내용을 유지하며 앱을 `apps`, ML 연구를 `research`, 문서를 `docs`, 디자인 참고 자료를 `design`으로 분리한다. iOS는 기능별 폴더와 Domain·Infrastructure·DesignSystem으로 재배치한다.

Xcode 프로젝트·타깃·스킴은 Orot으로 통일하고 기존 Bundle ID, Swift 모듈 이름 `FocusSense`, 저장 데이터 식별자는 유지한다. 실제 확장 기능을 구현하기 전에는 위젯·Live Activity 타깃이나 빈 Swift 타입을 만들지 않는다.

## 이번 단계에서 보존하는 동작

기존 4탭 화면, 하이브리드 감지, ML 모델, 알림과 저장 동작을 보존한다. 제품 기획의 3탭, 밤하늘, 미확인 시간 정책과 새 감지 엔진은 후속 변경이다.

## 후속 작업

세션 상태·시간 계산 분리, 기존 기록 이전 정책, 카메라 미사용 세션 정책, 새 감지 기준, 별 생성 규칙을 결정하고 구현한다. 데이터·모델 대용량 파일 관리 및 기존 테스트의 API 불일치도 별도로 정리한다.
